## Version Format

Releases should follow semantic versioning: `MAJOR.MINOR.PATCH`

- **MAJOR** — Breaking changes, major overhauls (e.g., 1.0.0 → 2.0.0)
- **MINOR** — New features, additive changes (e.g., 0.1.0 → 0.2.0)
- **PATCH** — Bug fixes, small tweaks (e.g., 0.1.0 → 0.1.1)
