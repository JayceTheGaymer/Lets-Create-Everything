# Let's Create Everything

A Create-powered journey that slows the early game without making it a grind, and makes every new tool feel like an achievement worth building toward.

This modpack rethinks early-game progression with custom recipes and new tools, all while making sure that the game doesn't feel like a grind. Start with nothing but rocks and sticks, work your way through a hand-tuned progression chain where everything feels more rewarding. Featuring a deep roster of Create addons, immersion focused mods, and a curated selection of quality-of-life and decoration mods, the pack is designed for players who want to get a little more out of their Minecraft experience.

Custom quests will guide you through your journey so you won't feel lost even with the numerous custom changes we've put in place. Not a fan of quests? No worries, they don't lock your progression at all and you can still use tools like JEI to look up the custom recipes.

Currently in active development.



## Pack Details
Built on Minecraft 1.21.1 using NeoForge.



## Key Features

- **Slowed Early-Game Progression** — Rock to stone to copper to iron, accomplished through Create's mechanical systems
- **Custom Recipes** — Hand-tuned via KubeJS and custom mods.
- **Deep Create Integration** — A large roster of Create addons including Aeronautics, Steam 'n' Rails, Slice & Dice, and more
- **Immersive World** — Terralith, YUNGs,curated ambient mods, and many more for an enhanced and more immersive atmosphere.
- **Optional Quests** — Optional guided progression via quests that are great if you are learning mods like Create.

Found a bug or have a suggestion? Please use the [issue templates](https://github.com/JayceTheGaymer/Lets-Create-Everything/issues/new/choose) to submit a report. When filing a bug report, include:

- Modpack version
- Whether the issue occurs with shaders on or off
- Whether the issue occurs with Distant Horizons on or off
- Steps to reproduce
- Crash log (if applicable) via a paste service like [mclo.gs](https://mclo.gs)
